# ImgPDF-Toolbox 🛠️📄

**ImgPDF-Toolbox** es una suite de escritorio ligera, rápida y de código abierto para la conversión, manipulación y optimización de imágenes y archivos PDF. Permite unir, separar y convertir documentos de forma local sin enviar datos a servidores externos, garantizando privacidad y velocidad.

---

## 🚀 Características

* **Conversión Bidireccional:**
  * PNG / JPG a PDF
  * PDF a imágenes (PNG / JPG con selección de densidad DPI y color de fondo)
* **Herramientas PDF Avanzadas:**
  * **Separar PDF:** Extracción en hojas individuales, corte por bloques de páginas o extracción de rangos específicos.
  * **Unir PDF:** Fusión de múltiples documentos en una cola personalizada en el orden exacto deseado.
* **Procesamiento Local:** Ejecución 100% en tu equipo mediante Ghostscript e ImageMagick.
* **Privacidad Total:** Sin conexión a la nube ni recopilación de datos.

---

## 📋 Requisitos Previos

Para ejecutar o compilar el proyecto en modo de desarrollo necesitas:

1. [Node.js](https://nodejs.org/) (versión 18 o superior)
2. [ImageMagick](https://imagemagick.org/)
3. [Ghostscript](https://www.ghostscript.com/)
